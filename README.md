# 우리 애랑 왜 이래?

부모와 자녀의 생년월일시를 바탕으로 생활 속 대화와 갈등을 돌아보는 모바일 우선 관계 리포트입니다. **정보 입력 → 분석 연출 → 관계 리포트 → PNG·요약 링크 공유**까지 브라우저에서 동작합니다.

React + TypeScript + Vite + Tailwind CSS로 구현했으며 서버·DB·API 키 없이 정적으로 배포할 수 있습니다. 사주 해석과 수치는 재미와 참고를 위한 서비스 자체의 콘텐츠 모델이며, 검증된 심리 진단이나 관계의 성공 확률이 아닙니다.

## 실행과 검증

Node.js 24 권장(최소 22.12).

```bash
npm install
npm run dev
npm test
npm run build
npm run format:check
npm run audit:content
```

개발 주소는 `http://localhost:5173`입니다. 브라우저 통합 테스트는 Chromium 설치 후 실행합니다.

```bash
npx playwright install --with-deps chromium
npm run test:e2e
```

`PLAYWRIGHT_BROWSERS_PATH`를 지정했다면 설치와 실행 시 같은 경로를 사용하세요.

## 현재 화면과 리포트

- 부모 → 아이의 2단계 입력에서 별명, 가족 역할, 양력·음력·윤달, 생년월일, 출생 시간 또는 시간 모름을 받습니다. 실제 날짜와 미래 출생일을 검증하며 이전 단계의 입력을 유지합니다.
- 결과 첫 화면은 관계 제목·유형·일상 장면을 보여줍니다.
- 갈등 버튼 최대 3개, 부모의 말 → 아이가 들은 말 → 바꿔 말하기, 아이를 보는 다른 관점, 화해 방법, 힘이 되는 한마디로 이어집니다.
- 계산 근거와 문구 선택 조건은 펼쳐서 확인합니다. 종합 점수와 5개 지표는 별도의 접힌 영역에 표시합니다.
- 1080 × 1440 PNG 카드와 요약 링크를 공유할 수 있습니다. 파일 공유 미지원·실패 시 다운로드로, 링크 공유 실패 시 클립보드와 수동 복사로 대체합니다. 공유 취소는 오류로 표시하지 않습니다.
- 최대 폭 480px, 키보드 포커스, 상태 알림, 모션 줄이기, 모바일 safe-area를 지원합니다.

## 조건 기반 문구 선택

`src/lib/relationshipTraits.ts`가 원국의 일간·오행 분포·천간 음양·지지 관계를 특성 수치와 근거 ID로 변환합니다. 특성 수치는 서비스의 해석 규칙이며 실제 성격의 측정값이 아닙니다.

`src/lib/copySelector.ts`는 특성 조건·아이의 만 나이·부모 역할에 맞는 카피를 걸러 우선순위, 조건 수, 안정적인 ID 순서로 선택합니다. `src/lib/report.ts`가 이를 관계 리포트로 조합합니다. 같은 입력과 같은 기준일·모델 버전은 같은 결과를 만듭니다. 기준일은 기본적으로 한국 날짜이며, 아이 나이가 바뀌면 연령별 장면이 달라질 수 있습니다. 음력 생일은 양력으로 변환한 후 만 나이를 계산합니다.

콘텐츠는 `src/data/relationshipArchetypes.ts`, `conflictTriggers.ts`, `naggingTranslator.ts`, `childPerspective.ts`, `reconciliationTips.ts`, `powerPhrases.ts`에서 관리합니다. 공통 화면 문구는 `serviceCopy.ts`, 수치 규칙은 `traitRules.ts`, 근거 설명은 `evidenceDescriptions.ts`에 있습니다.

`src/data/reportTestCases.ts`의 12개 고정 조합을 `npm run audit:content`로 확인할 수 있습니다. 2026-09-11 기준 관계 유형 8종, 대화 장면 9종, 갈등 버튼 조합 10종이 선택됩니다. 전체 결과는 [콘텐츠 검증 기록](docs/content-audit.json)에 있습니다.

## 원국과 보조 점수

### 사주 원국

임의의 연월일 공식 대신 **manseryeok 2.0.0을 고정**해 사용합니다. [`calculateFourPillars`와 오행·음력 변환 API](https://github.com/yhj1024/manseryeok)를 호출하여 연주·월주·일주·시주, 천간·지지와 오행을 얻습니다.

- 양력·음력 및 윤달 입력을 라이브러리에 전달합니다.
- 한국 표준시 KST, 진태양시 보정 없음, `dayBoundary: 'midnight'`를 명시합니다.
- 연주와 띠는 단순 출생연도 나머지 연산이 아닌 **입춘 절입 기준**, 월주는 절기 기준입니다.
- 오행 구성은 사용 가능한 각 기둥의 천간 1개와 지지 1개를 같은 비중으로 셉니다. 지장간·계절 세력·용신 분석은 하지 않습니다.
- **시간 미상:** API에 필요한 시각은 정오로 넣어 연·월·일을 산출하지만, 반환 데이터에서 시주를 제거하고 오행도 6개만 셉니다. 해당 시주를 점수에 사용하지 않습니다.
- 시간 미상일 때 같은 날짜 00:00과 23:59의 연·월주가 다르면 절기 경계 불확실성을 표시합니다. 실제 시간이 알려지면 띠 또는 월주가 달라질 수 있습니다.

### 궁합 규칙 (콘텐츠 모델 v1)

이 가중치는 전통 개념을 가족 관계 콘텐츠로 표현하기 위한 **서비스 자체의 설명 가능한 규칙**입니다. 정통 궁합의 유일한 공식이나 검증된 진단이라고 주장하지 않습니다. 난수·이름 해시·현재 시각으로 점수를 바꾸지 않습니다. 같은 유효한 출생 정보와 같은 엔진 버전은 항상 같은 수치와 문구를 만듭니다. 이름과 가족 관계는 표시 문구에만 반영됩니다.

**지지 쌍의 친화도**는 아래 값을 합하고 `[-1, 1]`로 제한합니다. 같은 지지는 기본 `+0.15`이며 자형이 있다면 함께 반영합니다. 한 쌍에 여러 관계가 있으면 모두 반영합니다.

| 요소 |                            값 | 적용                                                      |
| ---- | ----------------------------: | --------------------------------------------------------- |
| 육합 |                         +1.00 | 자축, 인해, 묘술, 진유, 사신, 오미                        |
| 충   |                         -1.00 | 자오, 축미, 인신, 묘유, 진술, 사해                        |
| 형   |                         -0.55 | 자묘, 인사·사신·신인, 축술·술미·미축, 진진·오오·유유·해해 |
| 파   |                         -0.35 | 자유, 축진, 인해, 묘오, 사신, 미술                        |
| 해   |                         -0.45 | 자미, 축오, 인사, 묘진, 신해, 유술                        |
| 삼합 | 전체 평균에 +0.15 / 완성 그룹 | 신자진, 해묘미, 인오술, 사유축                            |

형은 이 모델에서 방향을 구분하지 않는 쌍 규칙으로 단순화했습니다. 삼합은 두 사람의 사용 가능한 지지를 합쳐 **서로 다른 세 지지가 모두** 존재하고 양쪽에 해당 그룹의 지지가 있을 때만 인정합니다. 두 글자만 있는 반합은 삼합으로 계산하지 않습니다.

**종합 요소:**

| 기호 | 요소                                              | 비중 |
| ---- | ------------------------------------------------- | ---: |
| A    | 연지 친화도 (띠 관계)                             |  20% |
| B    | 두 사람의 모든 지지 교차 쌍 평균 + 완성 삼합 보정 |  30% |
| C    | 일간 오행: 상생 +1, 동일 +0.45, 상극 -0.45        |  20% |
| D    | 오행 보완성 0~~1을 -1~~1로 변환                   |  20% |
| E    | 시지 친화도, 두 사람 모두 시간을 아는 경우        |  10% |

오행은 목→화→토→금→수 순서의 상생 관계를 사용하며 부모→아이/아이→부모 방향은 동등하게 취급합니다. 보완성은 각 오행에 대해 `상대가 20%보다 부족한 비율`을 `내가 제공하는 비율`로 채울 수 있는 양을 양방향으로 합산하고, `0.8`로 나눈 뒤 최대 1로 제한합니다.

```text
weighted = 0.2A + 0.3B + 0.2C + 0.2(2D - 1) + 0.1E
core = 76 + 20 × weighted / 사용한 비중의 합
```

한 사람이라도 시간이 없으면 E를 완전히 빼고 비중의 합 `0.9`로 정규화합니다. B의 교차 쌍 수도 실제 사용한 3~4개 기둥에 맞춰 나눕니다.

**다섯 케미 점수:** 공통 core를 40~50% 사용하면서 서로 다른 요소를 섞습니다. M은 월지 친화도, J는 일지 친화도, T는 완성 삼합 수입니다.

```text
성격 = 0.50 × core + 0.50 × (77 + 12C + 6J)
대화 = 0.50 × core + 0.50 × (76 + 13B + 7C)
생활 = 0.45 × core + 0.55 × (74 + 12M + 10E)  // 미상 E 항 제외
회복 = 0.50 × core + 0.50 × (76 + 13D + 6B)
성장 = 0.40 × core + 0.60 × (79 + 14D + 상극일 때 4 + 3T)
최종 = 0.65 × core + 0.35 × 다섯 케미 점수의 평균
```

각 세부 점수와 최종 점수는 반올림 후 **45~98** 범위로 제한합니다. 관계의 차이를 반드시 감점으로만 표현하지 않도록 성장 점수에도 반영합니다. 실제 가족 관계가 실패할 확률 등으로 읽히는 문구나 근거 없는 전국 상위 퍼센트는 사용하지 않습니다.

## 공유와 개인정보

출생 입력은 React 메모리에서 계산에 사용하며 localStorage·sessionStorage·쿠키·서버에 저장하지 않습니다. 실제 메모리 회수 시점은 브라우저가 관리합니다.

`src/utils/share.ts`는 공유할 필드만 복사합니다. v2 공유에는 **공개용 별명, 가족 역할, 관계 제목·유형, 갈등 버튼 제목 하나, 힘이 되는 한마디**만 포함합니다. 출생일시·만 나이·원국·특성·근거·점수는 공유하지 않습니다. PNG도 같은 요약 객체만 사용합니다.

공유 URL은 query를 비우고 `/#report=…` fragment에 Base64URL 요약을 담습니다. Base64는 암호화가 아니며 링크를 받은 사람과 공유한 앱, 브라우저 방문 기록에서 내용을 볼 수 있습니다. 파서는 버전·길이·역할·문자열을 검증하고 허용되지 않은 필드를 제거합니다. 서버 서명이 없으므로 결과의 진위를 보증하지 않습니다.

기존 `/#result=…` v1 링크는 `src/utils/legacyShare.ts`로 읽어 요약 화면으로 변환합니다. 기존 링크 자체에 포함된 공개 데이터는 그대로 남으므로 v2의 축소된 공개 범위는 새로 생성한 링크에 적용됩니다.

## 배포

Cloudflare Pages 설정은 저장소 루트, 빌드 명령 `npm run build`, 출력 디렉터리 `dist`, Node.js 24입니다. `dist`를 정적 호스팅에 업로드할 수도 있습니다. 실제 계정 배포와 도메인 연결은 수행하지 않았습니다.

fragment 라우팅을 사용하므로 별도 서버 라우팅은 필요 없습니다. `public/_headers`에는 CSP·프레임 차단·MIME sniffing 차단·referrer 정책이 있습니다. 폰트는 자체 호스팅하며 외부 분석 스크립트는 없습니다.

## 검증 범위와 한계

이번 검증에서 단위 테스트 67개와 브라우저 테스트 19개가 통과했습니다(브라우저 테스트는 최초 16개 통과 후 실패한 3개 재검증 통과). 빌드와 포맷 검사도 통과했습니다.

단위 테스트는 계산 경계·음력·시간 미상·문구 조건과 다양성·연령 필터·근거 추적·v1/v2 공유를 검증합니다. 브라우저 테스트는 12개 실제 입력과 PNG 저장·공유 대체 동작·입력 오류·반응형을 검증합니다. 네이티브 공유는 브라우저 stub 검증이며 iOS Safari·Android 실기기 검증은 별도로 필요합니다.

출생지·해외 시간대·진태양시·역사적 서머타임 선택, 지장간·용신·대운·세운은 지원하지 않습니다. 시간 미상 절기 당일은 정오 기준 잠정 결과입니다. 카카오 전용 SDK, QR 코드, 개인별 동적 OG 이미지, 서버 기반 짧은 링크는 없습니다. 메신저마다 URL fragment 처리 제한이 있을 수 있습니다.

일러스트는 직접 작성한 SVG입니다. 외부 폰트와 패키지의 출처·라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.
